# 픽셀 오피스 대시보드 (`office/index.html`)

ChatDev 스타일의 **픽셀 아트 가상 사무실**입니다. 단일 HTML 파일(외부 스크립트·이미지 없음)이고, 캔버스에 코드로 직접 그립니다.
AI 직원(Claude 서브에이전트) 한 명이 캐릭터 한 명이며, 부서(방)별 책상에 앉아 일하고, 상태에 따라 움직이고, 말풍선을 띄웁니다.

## 실행

| 방법 | 결과 |
|---|---|
| `python scripts/office_server.py` (리눅스: `python3`) → http://127.0.0.1:8765 | **LIVE** — 2초마다 `GET /api/state` 를 읽어 실제 직원 상태를 표시 |
| `office/index.html` 을 그냥 열기 (`file://`) 또는 서버가 꺼져 있을 때 | **DEMO** — 가짜 직원 18명이 일하는 시뮬레이션 + `DEMO` 배지/안내 문구. 서버가 켜지면(6초 간격으로 재시도) 자동으로 LIVE 로 전환. 반대로 LIVE 도중 연결이 끊기면 마지막 실데이터를 유지한 채 "연결 끊김"을 표시하고, **연속 3번(약 6초)** 실패해야 DEMO 로 바뀝니다 |

오프라인에서도 동작합니다. 픽셀 폰트(Galmuri `2.40.3`, jsDelivr)는 선택 사항이며 못 받으면 시스템 한글 폰트/monospace 로 대체됩니다.

## 화면 구성

- **오피스 캔버스** (448×352 논리 px, 정수 배율 + `image-rendering: pixelated`)
  - 대표실(중앙, 러그에 `SHREW AI CO.`) · 리서치(책장) · 기획·디자인(화이트보드+원탁) · 제작(컴퓨터 책상 8석+8석) · 검수(모니터 달린 원탁) · 마케팅(포스터 벽) · 재무·법무(금고+서류함)
  - 창문은 실제 시각(낮/저녁/밤)에 맞춰 바뀌고, 벽시계는 실제 시간을 가리킵니다.
- **직원 캐릭터**: id 해시로 머리색·머리 모양·피부·셔츠색이 정해지는 치비 스프라이트(역할별 소품: 대표 넥타이, 안경, 베레모, 헤드폰). 가슴 배지 색 = 역할 색.
- **오른쪽 패널**(좁은 화면에서는 아래): KPI 카드(총 매출·이번 달 매출·순이익·상품 수 + 상태별 분포), 오너 승인 대기(읽기 전용), 실시간 이벤트 피드(최신이 위), 최근 상품 표.
- 캐릭터에 마우스를 올리거나(터치는 탭) 하면 id·직함·상태·작업·상품·갱신 시각 툴팁. 헤더의 "이름표 보기"로 모든 캐릭터에 id 표시.

## 역할 → 방, 상태 → 동작

| 역할 id (접두어) | 방 | 비고 |
|---|---|---|
| `ceo` | 대표실 | 큰 책상(모니터 2대) |
| `researcher` | 리서치 | |
| `pm`, `designer` | 기획·디자인 | 같은 방을 공유 (pm 먼저, designer 다음 좌석) |
| `maker` | 제작 | 8석 한 줄 + 둘째 줄 8석 |
| `qa` | 검수 | 원탁 둘레 6석 |
| `marketer` | 마케팅 | |
| `cfo` | 재무·법무 | |

`maker-7`, `qa-4` 처럼 인스턴스가 늘어나면 해당 방 안에 좌석을 자동 생성합니다(책상 → 모자라면 서 있는 자리). 좌석은 가능한 한 유지되어(`allocateSeats`) 직원이 늘고 줄어도 다른 직원이 자리를 옮기지 않습니다. 알 수 없는 역할(`intern-1` 등)은 대표실(로비)에 **서 있습니다**(남의 책상에 앉지 않음).

| state | 표현 |
|---|---|
| `idle` | 느린 숨쉬기, 가끔 눈 깜빡임, 모니터 대기화면 |
| `working` | 타이핑(손이 번갈아 움직임), 모니터에 코드가 깜빡임 |
| `meeting` | 방의 원탁으로 걸어가 의자에 앉아 대화(입 모양·손짓). 검수실은 제자리 |
| `blocked` | 붉은 틱 깜빡임 + 흔들림 + 땀방울, `⚠` 말풍선, 모니터 빨간 화면 |
| `done` | 만세 + 반짝이, `✓` 말풍선, 모니터 초록 체크 |

말풍선은 상태 파일의 `bubble` 필드(이모지 또는 짧은 텍스트)를 보여줍니다. 계약대로 6글자(이모지는 글자 단위)까지만 쓰고, blocked/done 은 `⚠`/`✓` 고정입니다.
툴팁·피드·승인·상품 패널의 아주 긴 문자열은 잘라서 보여주고(`clip`), `constructor` 같은 id/상태 값이 와도 라벨 표가 오염되지 않게 자기 속성만 조회합니다(`own`).

## 데이터 계약 (docs/90_시스템_인터페이스.md §2-4)

`GET /api/state` → `{now, agents[], events[], kpis{}, approvals[], products[]}`.
모든 필드는 누락/빈 값/잘못된 타입이어도 안전하게 정규화됩니다(`normalizeState`) — 응답이 깨져도 화면이 죽지 않고, 가져오기에 실패하면 DEMO 로 전환합니다. 서버/CSV 에서 온 모든 문자열은 HTML 이스케이프 후 출력합니다.

## 코드 구조 (`<script>` 안)

`1 CONSTANTS` → `2 UTILS`(해시·색·₩ 포맷·상대시간) → `3 DRAW HELPERS`(픽셀 프리미티브, 5×7 비트맵 폰트, 베이크 캐시) → `4 LAYOUT`(좌석 생성/배정, 순수 함수) → `5 SCENE`(바닥·벽·방 장식, 오프스크린에 1회 렌더) → `6 FURNITURE`(책상·테이블·모니터, 동적) → `7 SPRITES` → `8 ACTORS & RENDER`(60fps `requestAnimationFrame`, y-정렬) → `9 DATA`(폴링은 렌더 루프와 분리, DEMO 시뮬레이터) → `10 UI PANEL` → `11 BOOT`.

새 방/좌석을 바꾸려면 `ROOMS`, `DESKS`, `TABLES`, `SIGNS` 상수만 고치면 됩니다.
브라우저 콘솔에서 `window.__OFFICE__` 로 내부 함수(`seatFor`, `allocateSeats`, `normalizeState`, `makeDemo` …)를 직접 호출해 볼 수 있습니다.
