# Notion 템플릿 크리에이터 신청서 — 답변 초안

> 제출과 약관 동의는 오너가 직접 한다. 아래는 붙여넣기용 초안이며, 사실과 다른 부분은 오너가 고친다.
> 작성일: 2026-10-15

## 주의 (리서치 중간 결과, 최종은 docs/00_전략_Strategy.md)
- Stripe 공식 지원 국가 목록에 한국이 없어 Stripe 직접 가입은 안 된다. 다만 Notion 마켓플레이스는 Stripe Connect(플랫폼 경유) 방식이라, 한국 크리에이터 정산이 되는지는 승인 후 Stripe 연결 단계에서만 확실히 알 수 있다. 리서처가 본 Notion 정산 안내에는 한국 최소 정산액(40,000원)이 적혀 있었다고 하나, 연결 단계에서 다시 확인한다.
- 승인까지 수개월 걸린다는 보고가 있다. 승인만 기다리지 말고 Gumroad·크몽 판매를 병행한다.
- 수수료(리서치 보고): 판매액의 8% + 건당 $0.40, 미국 외 판매자는 환전 수수료 1% 추가. 정산은 격주.

## 문항별 답변

**1. 현재 템플릿을 판매하고 계신가요?** → `아니요`

**2. 어떤 유형의 템플릿을 판매할 계획인가요? 목표 고객은 누구인가요?**

한국어:
```
두 갈래의 한국어 우선 템플릿을 만들 계획입니다.
1) 개발·데이터 학습과 취업 준비: 일간/주간 회고, 학습 로그, 프로젝트 관리, 포트폴리오 정리, 지원 현황 트래커. 대상은 부트캠프 수강생, 비전공 개발 입문자, 주니어 개발자입니다. 저는 AI 부트캠프를 수강하며 회고와 포트폴리오를 실제로 노션으로 관리해 왔습니다.
2) 1인 프리랜서·사이드 프로젝트 운영: 상품/서비스 목록, 문의·외주 진행, 승인 대기, 매출·비용 장부를 연결한 관리 템플릿. 대상은 크몽·숨고 같은 플랫폼에서 활동하는 1인 프리랜서와 소규모 판매자입니다. 제가 직접 운영 중인 노션 본사 페이지를 다듬어 상품화합니다.
한국어판을 먼저 내고 영어판을 함께 제공할 예정입니다.
```

English (리뷰어가 영어권일 수 있어 함께 준비):
```
I plan to publish Korean-first templates (with English versions) in two lines:
1) Study & job-search for developers and data learners: daily/weekly retrospectives, learning logs, project tracking, portfolio, and a job-application tracker. Audience: bootcamp students, career switchers, and junior developers. I have run my own AI bootcamp retrospectives and portfolio in Notion.
2) Operations for solo freelancers and small sellers: linked databases for products/services, inquiries and client work, approvals, and a revenue/expense ledger. Audience: solo freelancers on Korean marketplaces such as Kmong and Soomgo. It is productized from the workspace I use to run my own small business.
```

**3. 판매 중이거나 제작하신 다른 Notion 관련 제품 또는 서비스가 있으신가요?** → `아니요` (현재 없음. 선택지에 "없음"이 있으면 그것)

**4. Notion 커뮤니티 참여 / 인증서** → 해당 사항이 있으면 선택, 없으면 비워둠(필수 아님)

**5. 사업장 소재지는 어디인가요?** → `대한민국 (South Korea)` — 사실대로. 위 Stripe 주의 참고.

**6. 브랜드 링크 (필수, 최대 5개)** — 공개된 페이지가 최소 1개 필요하다.
- 1순위: 노션 "Shrew AI 템플릿 쇼룸" 공개 페이지 (AI가 비공개로 초안 작성 → 오너가 웹에 게시)
- GitHub 프로필: https://github.com/AhnJung-min (저장소는 비공개여도 프로필은 공개)
- 판매 계정이 생기면 추가: 크몽 전문가 페이지, Gumroad 스토어

**7. 추가로 알려주실 내용이 있나요?**

한국어:
```
템플릿 제작에는 AI 도구를 보조로 쓰고, 구조 설계와 최종 검수는 제가 직접 합니다. 모든 템플릿은 실제로 제가 쓰는 워크스페이스에서 먼저 사용해 본 뒤 판매합니다. 한국어 사용자를 위한 노션 템플릿은 아직 선택지가 적어서, 한국 학습자와 1인 프리랜서의 실제 업무 흐름에 맞춘 템플릿으로 기여하고 싶습니다.
```

English:
```
I use AI tools as assistants during production, but I design the structure and review every template myself, and I use each template in my own workspace before selling it. Korean-language Notion templates are still limited, and I want to offer templates built around the real workflows of Korean learners and solo freelancers.
```

**8. 이용약관 동의 체크박스** → 오너가 직접 약관과 "유료 템플릿 제작자 약관"을 읽고 체크.
